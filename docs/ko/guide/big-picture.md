# Big Picture Mode

라이브러리를 전체 화면으로 보여주는 컨트롤러 우선 뷰입니다 - 큼직한 타일, 최소한의 텍스트로
구성되어 있으며 마우스/키보드가 아니라 소파에서 게임패드만으로 완전히 탐색하도록 만들어졌습니다.

## 진입과 종료

타이틀 바의 Big Picture 버튼을 클릭하면 진입합니다. 작은 화면 상단 우측 컨트롤을 통해 데스크톱
뷰로 나가거나, Big Picture 내부에서 그리드와 슬라이드쇼 레이아웃을 전환할 수 있습니다.

## 컨트롤러 탐색

D-패드/아날로그 스틱으로 타일 간 포커스를 이동하고, 얼굴 버튼(face button)으로 확인/실행하며,
다른 버튼으로 뒤로 나갑니다. 어떤 물리적 버튼/축이 이 동작들에 매핑되는지는 활성화된
**Controller** 매핑 플러그인(Settings → Controller)에 따라 다릅니다 - 다른 컨트롤러 레이아웃은
수동으로 재구성하는 것이 아니라 다른 플러그인을 선택하는 문제입니다. 컨트롤러가 제대로 동작하지
않는 것 같다면, 해당 컨트롤러에 맞는 매핑 플러그인이 설치되어 선택되어 있는지 확인하세요.

## 부팅 시 자동 실행

Settings → App Settings에는 Concourse가 시작될 때마다 곧바로 Big Picture Mode로 진입하는 토글이
있습니다 - 해당 기기가 일반 데스크톱이 아니라 콘솔/미디어 센터 박스처럼 전용으로 쓰인다면
유용합니다.

## 슬라이드쇼 뷰

Big Picture 내 타일 그리드의 대안으로, 한 번에 한 게임의 아트워크를 전체 화면으로 순환 표시하며
여전히 컨트롤러로 완전히 탐색할 수 있습니다.
