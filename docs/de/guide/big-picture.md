# Big Picture-Modus

Eine Vollbild-Ansicht deiner Bibliothek, ganz auf Controller-Bedienung ausgelegt - große Kacheln,
minimaler Text, dafür gedacht, komplett mit einem Gamepad vom Sofa aus navigiert zu werden statt
mit Maus/Tastatur.

## Betreten und Verlassen

Klicke auf den Big-Picture-Button in der Titelleiste, um ihn zu betreten; ein kleines
Bildschirmsteuerelement (oben rechts) erlaubt es, zurück zur Desktop-Ansicht zu wechseln oder
innerhalb von Big Picture selbst zwischen Raster- und Diashow-Layout zu wechseln.

## Controller-Navigation

D-Pad/Analogstick bewegt den Fokus zwischen Kacheln; eine Face-Taste bestätigt/startet, eine
andere geht zurück. Welche physischen Tasten/Achsen diesen Aktionen zugeordnet sind, hängt von
deinem aktiven **Controller**-Mapping-Plugin ab (Settings → Controller) - ein anderes
Controller-Layout ist eine andere Plugin-Auswahl, nichts, das man von Hand umkonfiguriert. Wenn
sich dein Controller nicht richtig anfühlt, prüfe, ob ein passendes Mapping-Plugin installiert
und ausgewählt ist.

## Automatischer Start beim Booten

Settings → App Settings hat einen Schalter, um Concourse bei jedem Start direkt in den
Big-Picture-Modus starten zu lassen - nützlich, wenn die Maschine dediziert wie eine
Konsole/Media-Center-Box statt als allgemeiner Desktop verwendet wird.

## Diashow-Ansicht

Eine Alternative zum Kachelraster innerhalb von Big Picture - durchläuft deine Bibliothek und
zeigt jeweils das Artwork eines Spiels im Vollbild, weiterhin vollständig per Controller
navigierbar.
