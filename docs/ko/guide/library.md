# Library & Games

## 게임 추가하기

**수동으로**: "Add Game" 버튼은 제목과 실행 파일 경로(또는 `steam://run/<appid>`와 같은 런처
URI - [아래](#uri-launches-vs-direct-executables) 참고)를 입력받습니다. 소스 플러그인이 아직
다루지 않는 모든 것에 사용하세요.

**소스 플러그인을 통해**: 소스 플러그인을 설치하고 활성화하면(Settings → Source), Settings에
"Scan Now" 버튼이 나타나 해당 플러그인이 알고 있는 모든 게임을 찾아 라이브러리에 추가합니다.
나중에 다시 스캔을 실행해도 이미 라이브러리에 있는 게임은 중복 추가되지 않고 새로 설치된 게임만
반영됩니다(아래 중복 제거 참고).

## 게임 편집하기

게임의 상세 페이지를 열고(커버/제목을 클릭하거나 Edit 아이콘 클릭) 편집 모드로 전환하세요.
제목, 커버/배경 아트 URL, 설명(마크다운 지원), 출시일, 플랫폼을 재정의할 수 있습니다.
"Fetch Metadata" 버튼은 활성화된 메타데이터 제공자(Settings → Metadata Provider)를 현재
제목에 대해 다시 실행하여 찾은 내용을 채워 넣습니다 - 자동 가져오기가 무언가를 놓쳤거나,
게임을 처음 추가한 이후 제공자의 데이터가 변경되었을 때 유용합니다.

## 태그와 컬렉션

- **태그(Tags)**는 자유 형식 라벨("Co-op", "Backlog", "Completed")입니다 - Tags 사이드바 탭에서
  생성/이름 변경/삭제하고, 해당 게임의 상세 페이지에서 게임별로 할당합니다.
- **컬렉션(Collections)**은 시리즈/프랜차이즈("Final Fantasy")를 묶습니다 - 태그와는 별개의
  개념이며, 마찬가지로 자체 사이드바 탭에서 관리합니다.

두 가지 모두 일반 제목 검색과 함께 라이브러리 뷰의 검색/필터링을 지원합니다.

## 소스 간 중복 제거 {#deduplication-across-sources}

같은 게임이 수동으로 추가된 뒤 나중에 소스 플러그인 스캔에서도 발견되거나(또는 서로 다른 두
소스 플러그인에서 각각 발견되면), Concourse는 중복으로 표시하는 대신 제목을 기준으로 매칭하여
하나의 항목으로 병합합니다. 둘 이상의 소스가 같은 제목을 찾은 경우, Source 탭의 우선순위 순서에서
더 뒤에 있는 플러그인이 실행 경로/플랫폼을 결정합니다(다른 플러그인을 우선시하고 싶다면 목록
순서를 재정렬하세요).

같은 제목의 두 항목을 정말로 별도로 유지하고 싶다면(예: 같은 게임의 서로 다른 두 버전), 게임의
편집 폼에 "Keep separate from plugin scans" 체크박스(`skip_dedup`)가 있습니다 - 이를 체크하면
해당 특정 항목을 병합 로직에서 제외합니다.

## 오프라인 번역 {#offline-translation}

게임의 제목과 설명은 완전히 오프라인으로 현재 UI 언어로 번역할 수 있습니다 - 외부 번역 서비스
없이, 기기 밖으로 아무것도 나가지 않습니다. 게임의 상세 페이지에서 "Translate" 버튼을 누르면
세 그룹으로 나뉜 메뉴가 열립니다(스크롤하거나 화살표 키로 그룹 간 이동):

- **Translate** - 제목만, 설명만, 또는 둘 다 번역합니다. 다른 모델을 선택해 다시 실행하면 해당
  필드의 이전 번역을 덮어씁니다.
- **Show** - 번역된 텍스트와 원문 사이를 필드별로 또는 둘 다 함께 전환합니다. 이 선택은 게임별로
  기억되므로, 나중에 게임을 다시 열면 해당 게임에 대해 마지막으로 선택한 상태가 그대로 표시됩니다.
- **Remove** - 필드(또는 둘 다)의 캐시된 번역을 지우고, 아무것도 캐시하지 않은 원문 상태로
  되돌립니다.

**최초 설정**(Settings): 번역 엔진을 한 번 다운로드(작은 용량의 1회성 다운로드)한 다음, 드롭다운에서
모델을 선택하고 그것도 다운로드하세요. 크기/RAM과 품질을 맞바꾸는 몇 가지 모델 등급이 제공되며,
모두 CPU에서만 동작하므로 더 작은 등급일수록 게임 실행 중에도 더 빠르게 번역하고 메모리를 덜
사용합니다. 한 등급은 무검열(uncensored) 모델로, 안전 튜닝된 모델이 정당한 제3자 텍스트 번역을
거부하는 일 없이 NSFW 게임 자체의 설명을 번역하기 위한 용도입니다.

캐시된 번역은 만들어질 때의 UI 언어에 종속됩니다 - UI 언어를 전환하거나 게임의 원본 제목/설명을
편집하면 자동으로 무효화됩니다(새 언어나 수정된 텍스트에 대한 최신 번역을 얻으려면 다시
번역하세요).

## URI 실행과 직접 실행 파일 비교 {#uri-launches-vs-direct-executables}

일부 소스 플러그인(Steam, Epic)은 직접적인 `.exe` 경로가 아니라 플랫폼 URI
(`steam://run/...`, `com.epicgames.launcher://...`)를 통해 게임을 실행합니다. 해당 플랫폼
자체가 게임을 시작하도록 지시받는 방식이 그렇기 때문입니다. 이런 경우 플레이타임 추적 방식이
다르게 동작합니다 - 아래 [Playtime Tracking](#playtime-tracking)를 참고하세요.

## 플레이타임 추적 {#playtime-tracking}

직접 실행 파일 경로의 경우, Concourse는 실제 프로세스를 기다렸다가 종료되면 실제 세션(시작/종료/지속
시간)을 기록합니다. URI로 실행된 게임의 경우 같은 방식으로 기다릴 프로세스 핸들이 없으므로 세션이
동일한 방식으로 기록되지 않습니다 - Stats 탭의 "Recently Played"/총 시간 수치는 각 실행 방식에서
실제로 추적 가능한 내용을 반영합니다.
