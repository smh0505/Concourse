features:
  - title: Плагины источников (Source Plugins)
    details: Сканируют и запускают игры с платформы (Steam, GOG, Epic, фронтенд эмулятора, ...).
  - title: Плагины тем (Theme Plugins)
    details: Переоформляют цвета, шрифты и визуал карточек - чистый манифест данных, код не требуется.
  - title: Плагины поставщиков метаданных (Metadata Provider Plugins)
    details: Получают описания, даты выхода и арт из внешней базы данных.
  - title: Плагины-обёртки (Wrapper Plugins)
    details: Запускают игру через слой совместимости (например, локальный эмулятор), которым плагин управляет самостоятельно.
