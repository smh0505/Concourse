# Начало работы

Concourse - это настольное приложение, которое объединяет игры из множества источников в одну
библиотеку, с полноэкранным консольным режимом "Big Picture" для навигации в первую очередь с
геймпада. Это руководство описывает повседневное использование приложения. Если вы вместо этого
разрабатываете плагин, смотрите [документацию для плагинов](/ru/plugins/).

## Установка

Скачайте последний установщик со [страницы релизов](https://github.com/smh0505/Concourse/releases/latest)
(пока только для Windows). Concourse автоматически проверяет и устанавливает собственные
обновления во время работы - повторно скачивать вручную после первой установки не нужно.

## Первый запуск

При первом запуске ваша библиотека пуста. Заполнить её можно двумя способами, и большинство
пользователей в итоге используют оба:

1. **Добавить игру вручную** - кнопка "Add Game" (боковая панель) принимает название и путь к
   исполняемому файлу, для всего, что ещё не покрыто плагином источника (эмулятор, загрузка с
   itch.io, ...).
2. **Установить плагин источника** - вкладка Settings → Source позволяет установить плагин,
   который сканирует существующую платформу (Steam, GOG, Epic, ...) на предмет уже имеющихся у
   вас игр и синхронизирует этот список при последующих сканированиях. См. [Библиотека и
   игры](./library) о том, как работают сканирование/дедупликация, и [Плагины и
   темы](./plugins-and-themes) о том, как фактически установить плагин.

## Где что находится

- **Library** (боковая панель) - сетка/список ваших игр, вид по умолчанию.
- **Stats** - общее число игр/часов, "Most Played", "Recently Played".
- **Tags** / **Collections** - два отдельных понятия организации: теги - это произвольные метки
  ("Co-op", "Backlog"); коллекции группируют серию/франшизу ("Final Fantasy"). Управляйте обоими
  на их собственных вкладках боковой панели, либо назначайте их для отдельной игры на странице
  её деталей.
- **Settings** - всё, что связано с плагинами/темами/настройками приложения, см. [Плагины и
  темы](./plugins-and-themes); там же настраивается офлайн-перевод - см. [Библиотека и
  игры](./library#offline-translation).
