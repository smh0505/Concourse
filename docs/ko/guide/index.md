# 시작하기

Concourse는 여러 소스의 게임을 하나의 라이브러리로 통합하는 데스크톱 앱으로, 컨트롤러 우선 탐색을 위한
콘솔 같은 전체 화면 "Big Picture" 모드를 제공합니다. 이 가이드는 앱을 일상적으로 사용하는 방법을
다룹니다. 플러그인을 만들고 있다면 [플러그인 문서](/ko/plugins/)를 참고하세요.

## 설치하기

[Releases 페이지](https://github.com/smh0505/Concourse/releases/latest)에서 최신 설치 파일을
다운로드하세요 (현재는 Windows만 지원). Concourse는 실행 중일 때 자체 업데이트를 자동으로 확인하고
설치하므로, 최초 설치 후에는 수동으로 다시 다운로드할 필요가 없습니다.

## 첫 실행

처음 실행하면 라이브러리는 비어 있습니다. 라이브러리를 채우는 방법은 두 가지이며, 대부분의 사용자는
두 가지를 모두 사용하게 됩니다:

1. **게임을 수동으로 추가하기** - "Add Game" 버튼(사이드바)은 소스 플러그인이 아직 다루지 않는
   모든 것(에뮬레이터, itch.io 다운로드 등)을 위해 제목과 실행 파일 경로를 입력받습니다.
2. **소스 플러그인 설치하기** - Settings → Source 탭에서 이미 보유 중인 플랫폼(Steam, GOG, Epic 등)의
   게임을 스캔하는 플러그인을 설치할 수 있으며, 이후 스캔에서도 목록을 계속 동기화합니다. 스캔/중복
   제거가 어떻게 동작하는지는 [Library & Games](./library)를, 실제로 플러그인을 설치하는 방법은
   [Plugins & Themes](./plugins-and-themes)를 참고하세요.

## 각 기능의 위치

- **Library** (사이드바) - 게임의 그리드/리스트 뷰, 기본 화면입니다.
- **Stats** - 총 게임 수/시간, 가장 많이 플레이한 게임, 최근 플레이한 게임.
- **Tags** / **Collections** - 서로 다른 두 가지 정리 개념입니다: 태그는 자유 형식 라벨
  ("Co-op", "Backlog")이고, 컬렉션은 시리즈/프랜차이즈("Final Fantasy")를 묶습니다. 각각의
  사이드바 탭에서 관리하거나, 게임의 상세 페이지에서 게임별로 할당할 수 있습니다.
- **Settings** - 플러그인/테마/앱 환경설정과 관련된 모든 것으로, [Plugins & Themes](./plugins-and-themes)를
  참고하세요. 오프라인 번역을 설정하는 곳이기도 합니다 - [Library & Games](./library#offline-translation)를
  참고하세요.
