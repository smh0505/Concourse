# 插件与主题

Settings(设置)中有一个标签页面板,涵盖了每一种插件:**Source(来源)**、**Theme(主题)**、
**Metadata Provider(元数据提供方)**、**Controller(控制器)** 和 **Wrapper(包装器)**。如果你
是在开发插件而非安装插件,请参阅[插件文档](/zh-hans/plugins/) —— 本页是面向用户使用的部分。
当前维护中的插件/主题列表见[官方插件](./official-plugins)。

## 安装插件

从任意标签页点击 "Add Plugin"(添加插件)。你有两种选择:

- **精选注册表(Curated registry)** —— 一份经过审核、带哈希校验的已知良好插件列表。选择一个
  并点击 Install(安装);Concourse 会先根据一个固定的哈希值验证其内容,再进行安装,因此你得到
  的正是经过审核的内容。
- **粘贴 manifest URL** —— 通过直接粘贴指向其 `plugin.json` 的链接来安装其他任何插件。这适用
  于任何插件,无论其是否列在注册表中,但会跳过注册表路径所具备的哈希校验 —— 你是在直接信任该
  URL 的发布者。Concourse 仍会在你确认之前,展示该插件声明所需的内容(文件/注册表/网络访问、
  是否可运行其他程序)。

## 启用/禁用与排序

- **Source(来源)** 和 **Metadata Provider(元数据提供方)** 插件可独立多选启用(复选框) ——
  可同时运行多个来源插件和多个元数据提供方。它们的顺序很重要:对来源插件而言,顺序决定了当同一
  款游戏被多于一个插件发现时由谁胜出(参见[去重](./library#deduplication-across-sources));
  对元数据提供方而言,顺序决定了当多个提供方对某个字段(描述、发行日期、封面/背景美术)都有
  数据时由谁的答案胜出。可通过每个条目旁边的箭头重新排序这两份列表。
- **Theme(主题)** 和 **Controller(控制器)** 插件是互斥的(单选) —— 你始终只浏览一种皮肤,
  并同时只使用一种物理控制器映射。
- **Wrapper(包装器)** 插件(兼容层,例如区域模拟器)可多选启用,每个都可独立安装/管理,并可
  在某个游戏的编辑表单中按游戏单独选择。

## 更新

Concourse 会自动检查插件/主题更新(应用启动时、应用窗口获得焦点时,以及每次打开 Settings 或
Add Plugin 对话框时),并在有新版本可用的项目旁显示 "Update to vX.Y.Z"(更新到 vX.Y.Z)徽章。
点击即可原地更新。

## 卸载

每个已安装的(非内置)插件/主题在其所在行都有一个 Remove/Uninstall(移除/卸载)操作。管理自己
下载文件的主题以及来源/元数据/包装器插件(例如某个包装器已安装的运行时)也会一并清理这些文件,
而不只是清理 manifest 条目。
