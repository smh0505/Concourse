# Big Picture Mode

A full-screen, controller-first view of your library - large tiles, minimal text, meant to be
navigated entirely with a gamepad from a couch rather than a mouse/keyboard.

## Entering and leaving

Click the Big Picture button in the title bar to enter; a small on-screen control (top-right)
lets you exit back to the desktop view, or switch between grid and slideshow layouts within Big
Picture itself.

## Controller navigation

D-pad/analog stick moves focus between tiles; a face button confirms/launches, another backs
out. Which physical buttons/axes map to those actions depends on your active **Controller**
mapping plugin (Settings → Controller) - a different controller layout is a different plugin
selection, not something to reconfigure by hand. If your controller doesn't feel right, check
whether a mapping plugin matching it is installed and selected.

## Auto-launch on boot

Settings → App Settings has a toggle to launch straight into Big Picture Mode whenever
Concourse starts - useful if the machine is dedicated to acting like a console/media-center box
rather than a general desktop.

## Slideshow view

An alternative to the tile grid within Big Picture - cycles through your library showing one
game's art full-screen at a time, still fully controller-navigable.
