# はじめに

Concourseは、多くのソースからゲームを1つのライブラリに集約するデスクトップアプリで、コントローラー操作を前提とした
コンソールのような全画面「Big Picture」モードを備えています。このガイドでは、アプリを日常的に使う方法を説明します。
プラグインを開発する場合は、[プラグインドキュメント](/ja/plugins/)を参照してください。

## インストール

[Releasesページ](https://github.com/smh0505/Concourse/releases/latest)から最新のインストーラーをダウンロードしてください
(現時点ではWindowsのみ対応)。Concourseは起動後、自動的に自身のアップデートを確認・インストールします -
初回インストール後に手動で再ダウンロードする必要はありません。

## 初回起動

初回起動時、ライブラリは空です。ライブラリを構築する方法は2通りあり、ほとんどの人は両方を使うことになります。

1. **手動でゲームを追加** - サイドバーの「Add Game」ボタンでタイトルと実行ファイルパスを入力します。
   ソースプラグインでまだカバーされていないもの(エミュレータ、itch.ioのダウンロードなど)に使用します。
2. **ソースプラグインをインストール** - Settings → Sourceタブから、既存のプラットフォーム(Steam、GOG、Epicなど)を
   スキャンしてすでに所有しているゲームを見つけ、以降のスキャンでもそのリストを同期し続けるプラグインをインストール
   できます。スキャン/重複排除の仕組みについては[ライブラリとゲーム](./library)を、実際にプラグインをインストールする
   方法については[プラグインとテーマ](./plugins-and-themes)を参照してください。

## 各機能の場所

- **Library**(サイドバー) - ゲームのグリッド/リスト表示。デフォルトのビューです。
- **Stats** - 総ゲーム数/総プレイ時間、Most Played、Recently Played。
- **Tags** / **Collections** - 別々の2つの整理概念です。タグは自由形式のラベル(「Co-op」「Backlog」)、
  コレクションはシリーズ/フランチャイズをグループ化します(「Final Fantasy」)。それぞれ専用のサイドバータブから
  管理するか、ゲームの詳細ページからゲームごとに割り当てられます。
- **Settings** - プラグイン/テーマ/アプリ設定に関するすべてがここにあります。詳細は
  [プラグインとテーマ](./plugins-and-themes)を参照してください。オフライン翻訳の設定もここで行います - 詳細は
  [ライブラリとゲーム](./library#offline-translation)を参照してください。
