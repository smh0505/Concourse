# Big Pictureモード

ライブラリを全画面・コントローラー操作優先で表示するビューです - 大きなタイル、最小限のテキストで、
マウス/キーボードではなくソファからゲームパッドだけで完全にナビゲートすることを想定しています。

## 開始と終了

タイトルバーのBig Pictureボタンをクリックすると開始します。小さな画面上コントロール(右上)から
デスクトップビューに戻ったり、Big Picture内でグリッド表示とスライドショー表示を切り替えたりできます。

## コントローラーナビゲーション

D-パッド/アナログスティックでタイル間のフォーカスを移動し、フェイスボタンで確定/起動、別のボタンで
戻ります。どの物理ボタン/軸がこれらのアクションに対応するかは、有効な**Controller**マッピングプラグイン
(Settings → Controller)によって決まります - 異なるコントローラーレイアウトは手動での再設定ではなく、
別のプラグイン選択です。コントローラーの反応がおかしいと感じたら、そのコントローラーに合った
マッピングプラグインがインストールされ選択されているか確認してください。

## 起動時の自動起動

Settings → App Settingsには、Concourseの起動時に常にBig Pictureモードへ直接入るトグルがあります -
マシンが一般的なデスクトップではなくコンソール/メディアセンター機器として専用に使われている場合に便利です。

## スライドショービュー

Big Picture内のタイルグリッドの代替表示です - ライブラリを1度に1つのゲームのアートワークを全画面で
表示しながら巡回し、こちらも完全にコントローラーでナビゲートできます。
