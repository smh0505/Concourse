# プラグインとテーマ

Settingsには、あらゆる種類のプラグインを扱う1つのタブ付きパネルがあります: **Source**、**Theme**、**Metadata
Provider**、**Controller**、**Wrapper**。プラグインをインストールするのではなく開発している場合は、代わりに
[プラグインドキュメント](/ja/plugins/)を参照してください - このページはユーザー向けの内容です。現在メンテナンス
されているプラグイン/テーマの一覧は[公式プラグイン](./official-plugins)を参照してください。

## プラグインのインストール

任意のタブから「Add Plugin」をクリックします。2つの選択肢があります。

- **キュレーションされたレジストリ** - レビュー済みでハッシュ検証された、既知の安全なプラグインのリストです。
  1つ選んでInstallをクリックすると、Concourseはインストール前に固定ハッシュに対してコンテンツを検証するので、
  レビューされたものと完全に一致するものが得られます。
- **マニフェストURLを貼り付け** - `plugin.json`への直接リンクを貼り付けることで、それ以外の任意のプラグインを
  インストールできます。これはレジストリに掲載されているかどうかにかかわらずどんなプラグインでも使えますが、
  レジストリ経由で得られるハッシュ検証はスキップされます - そのURLを公開した相手を直接信頼することになります。
  それでもConcourseは、インストールを確認する前にそのプラグインが必要とすると宣言している内容
  (ファイル/レジストリ/ネットワークアクセス、他のプログラムを実行できるかどうか)を表示します。

## 有効化/無効化と順序

- **Source**と**Metadata Provider**プラグインは、それぞれ独立して複数有効化できます(チェックボックス) -
  複数のソースプラグインと複数のメタデータプロバイダを同時に実行できます。順序が重要です:
  ソースプラグインの場合、同じゲームが複数のプラグインで見つかったときにどちらが優先されるかを決定します
  ([重複排除](./library#deduplication-across-sources)を参照)。メタデータプロバイダの場合、複数のプロバイダが
  何かを持っているフィールド(説明、リリース日、カバー/背景アートワーク)ごとに、どのプロバイダの回答が
  優先されるかを決定します。どちらのリストも、各エントリの横にある矢印で並べ替えられます。
- **Theme**と**Controller**プラグインは排他的です(ラジオボタン) - 常に1つのスキンと1つの物理コントローラー
  マッピングだけを使用します。
- **Wrapper**プラグイン(ロケールエミュレータなどの互換レイヤー)は複数有効化でき、それぞれ独立して
  インストール/管理でき、各ゲームの編集フォームからゲームごとに選択できます。

## アップデート

Concourseはプラグイン/テーマのアップデートを自動的に確認し(アプリ起動時、アプリウィンドウのフォーカス時、
Settingsまたは Add Pluginダイアログを開いたとき)、新しいバージョンが利用可能なものの横に「Update to
vX.Y.Z」バッジを表示します。クリックするとその場でアップデートされます。

## アンインストール

インストール済み(組み込みでない)の各プラグイン/テーマには、それぞれの行にRemove/Uninstallアクションが
あります。自分でダウンロードしたファイルを管理するテーマやソース/メタデータ/ラッパープラグイン
(例えばラッパーのインストール済みランタイム)は、マニフェストエントリだけでなくそれらもクリーンアップします。
