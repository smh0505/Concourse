# Plugins & Themes

Settings에는 모든 종류의 플러그인을 다루는 하나의 탭 패널이 있습니다: **Source**, **Theme**,
**Metadata Provider**, **Controller**, **Wrapper**. 플러그인을 설치하는 것이 아니라 만들고
있다면 [플러그인 문서](/ko/plugins/)를 참고하세요 - 이 페이지는 사용자 측면입니다. 현재
유지보수 중인 플러그인/테마 목록은 [Official Plugins](./official-plugins)를 참고하세요.

## 플러그인 설치하기

아무 탭에서나 "Add Plugin"을 클릭하세요. 두 가지 방법이 있습니다:

- **큐레이션된 레지스트리(Curated registry)** - 검토를 거치고 해시로 검증된 알려진 안전한
  플러그인 목록입니다. 하나를 선택해 Install을 클릭하면, Concourse가 설치 전에 고정된 해시와
  내용을 대조 검증하므로 검토된 것과 정확히 동일한 내용을 받게 됩니다.
- **매니페스트 URL 붙여넣기** - `plugin.json`에 대한 직접 링크를 붙여넣어 다른 무엇이든 설치할
  수 있습니다. 레지스트리에 등록되어 있든 아니든 어떤 플러그인에도 동작하지만, 레지스트리
  경로에서 받는 해시 검증은 건너뜁니다 - 그 URL을 게시한 사람을 직접 신뢰하는 셈입니다.
  Concourse는 설치를 확정하기 전에 해당 플러그인이 선언한 필요 사항(파일/레지스트리/네트워크
  접근, 다른 프로그램 실행 여부)을 여전히 보여줍니다.

## 활성화/비활성화 및 순서 지정

- **Source**와 **Metadata Provider** 플러그인은 독립적으로 다중 활성화(체크박스)됩니다 - 여러
  소스 플러그인과 여러 메타데이터 제공자를 동시에 실행할 수 있습니다. 순서가 중요합니다: 소스
  플러그인의 경우 같은 게임이 둘 이상에서 발견될 때 어느 쪽이 우선하는지 결정하고
  ([중복 제거](./library#deduplication-across-sources) 참고), 메타데이터 제공자의 경우 둘
  이상이 같은 필드(설명, 출시일, 커버/배경 아트)에 대해 답을 가지고 있을 때 어느 제공자의 답이
  우선하는지 결정합니다. 각 항목 옆의 화살표로 목록 순서를 재정렬하세요.
- **Theme**와 **Controller** 플러그인은 배타적(라디오)입니다 - 항상 하나의 스킨을 사용하고
  하나의 물리적 컨트롤러 매핑을 사용합니다.
- **Wrapper** 플러그인(호환성 레이어, 예: 로케일 에뮬레이터)은 다중 활성화되며, 각각 독립적으로
  설치/관리할 수 있고, 게임의 편집 폼에서 게임별로 선택할 수 있습니다.

## 업데이트

Concourse는 플러그인/테마 업데이트를 자동으로 확인하며(앱 시작, 앱 창 포커스, Settings나 Add
Plugin 대화상자를 열 때마다) 새 버전이 있는 항목 옆에 "Update to vX.Y.Z" 배지를 표시합니다.
클릭하면 즉시 업데이트됩니다.

## 제거하기

설치된(내장이 아닌) 모든 플러그인/테마는 자기 행에 Remove/Uninstall 액션이 있습니다. 자체
다운로드 파일을 관리하는 테마와 소스/메타데이터/래퍼 플러그인(예: 래퍼가 설치한 런타임)은
매니페스트 항목뿐 아니라 해당 파일도 함께 정리합니다.
