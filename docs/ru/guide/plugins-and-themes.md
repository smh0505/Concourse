# Плагины и темы

Settings содержит одну панель с вкладками, охватывающую все виды плагинов: **Source**, **Theme**,
**Metadata Provider**, **Controller** и **Wrapper**. Если вы разрабатываете плагин, а не
устанавливаете его, см. [документацию для плагинов](/ru/plugins/) вместо этой страницы - здесь
описана пользовательская сторона. См. [Официальные плагины](./official-plugins) для актуального
списка поддерживаемых плагинов/тем.

## Установка плагина

Нажмите "Add Plugin" на любой вкладке. У вас есть два варианта:

- **Проверенный реестр (curated registry)** - рецензированный, проверенный по хэшу список
  заведомо надёжных плагинов. Выберите один и нажмите Install; Concourse проверяет его содержимое
  по зафиксированному хэшу перед установкой, так что вы получаете именно то, что было
  проверено.
- **Вставить URL манифеста** - установите что угодно другое, вставив прямую ссылку на его
  `plugin.json`. Это работает для любого плагина, есть он в реестре или нет, но пропускает
  проверку по хэшу, которую даёт путь через реестр, - вы напрямую доверяете тому, кто опубликовал
  этот URL. Concourse всё равно показывает, что плагин заявляет как необходимое (доступ к
  файлам/реестру/сети, может ли он запускать другие программы), прежде чем вы подтвердите
  установку.

## Включение/отключение и порядок

- Плагины **Source** и **Metadata Provider** независимо многократно включаемы (флажки) - можно
  одновременно запускать несколько плагинов источников и несколько поставщиков метаданных. Их
  порядок имеет значение: для плагинов источников он определяет, какой из них побеждает, если
  одна и та же игра найдена более чем одним (см. [дедупликацию](./library#deduplication-across-sources));
  для поставщиков метаданных он определяет, чей ответ побеждает по каждому полю (описание, дата
  выхода, обложка/фоновый арт), когда есть что сказать у более чем одного. Переставляйте любой из
  списков стрелками рядом с каждой записью.
- Плагины **Theme** и **Controller** взаимоисключающие (радиокнопки) - вы всегда просматриваете
  один скин и используете одну физическую раскладку контроллера одновременно.
- Плагины **Wrapper** (слои совместимости, например локальный эмулятор) многократно включаемы,
  каждый устанавливается/управляется независимо и выбирается для отдельной игры в форме
  редактирования этой игры.

## Обновления

Concourse автоматически проверяет обновления плагинов/тем (при запуске приложения, при фокусе
окна приложения, а также при каждом открытии Settings или диалога Add Plugin) и показывает значок
"Update to vX.Y.Z" рядом с чем-либо, для чего доступна более новая версия. Нажмите на него, чтобы
обновить на месте.

## Удаление

У каждого установленного (не встроенного) плагина/темы есть действие Remove/Uninstall в его
собственной строке. Темы и плагины source/metadata/wrapper, которые управляют собственными
скачанными файлами (например, установленное окружение обёртки), тоже их удаляют, а не только
запись в манифесте.
