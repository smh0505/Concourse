# Манифесты тем

Темы - единственный вид плагинов с существенно иной формой манифеста по сравнению с остальными -
сегодня сторонняя тема всегда относится к уровню только с данными (`runtime: "data"`): манифест
вообще без скомпилированного кода. См. [Справочник манифеста](./manifest-reference) для полей,
общих для всех видов плагинов (`id`/`name`/`version`/`kind`/`entry`/`runtime`); эта страница
охватывает поля, специфичные для тем.

## Поля

| Поле | Тип | Примечания |
|---|---|---|
| `cssVariables` | `Record<string, string>` | Пользовательские CSS-свойства (например, `"--color-base": "#1e1e2e"`), применяемые к `:root`, пока эта тема активна. Это всё содержимое темы только с данными. |
| `cardVisual` | JSON AST закрытого словаря | Переопределяет визуальную область обложки карточки игры (изображение-или-заполнитель) без необходимости в реальном коде. |
| `fontFaces` | массив объявлений шрифтов | Реальные файлы шрифтов для загрузки через `@font-face`. |

Один `cssVariables` уже является полной, валидной темой - `cardVisual`/`fontFaces` оба
опциональны, это дополнительные возможности по желанию.

## `cardVisual`: словарь узлов

`cardVisual` проверяется по закрытому набору типов узлов (`validateCardVisualAst` в
`theme/cardVisualAst.ts`) - в этом формате нет `eval`/`new Function`/вычисления выражений нигде,
так что не существует примитива выполнения кода, из которого мог бы вырваться злонамеренный
манифест. AST глубже 5 уровней или с более чем 50 узлами суммарно отклоняется сразу, как и любая
форма узла вне перечисленных ниже.

| Тип узла | Форма | Примечания |
|---|---|---|
| `if` | `{ type: "if", test: FieldRef, then: AstNode, else?: AstNode }` | Рендерит `then`, если referenced-поле истинно, иначе `else` (или ничего, если `else` опущен). |
| `element` | `{ type: "element", tag: "div" \| "span", class?: string, children?: AstNode[] }` | `tag` закрыт этими двумя неинтерактивными элементами - нет пути отрендерить `button`/`a`/что-либо, способное получить фокус или переходить по ссылке, что соответствует правилу, что действия футера остаются рендерингом хоста, никогда не под управлением темы. |
| `image` | `{ type: "image", class?: string, src: FieldRef, alt: FieldRef }` | Собственный тип узла, а не `element` с общим набором атрибутов - `src`/`alt` - единственные привязываемые атрибуты, существующие в этом формате, так что нет способа для манифеста внедрить произвольный атрибут (обработчик `onerror`, `style` содержащий `url(...)`). |
| `text` | `{ type: "text", content?: string, field?: FieldRef }` | Рендерит вычисленное значение `field`, если оно присутствует, иначе буквальную строку `content`. |

`FieldRef` (используется `if.test`, `image.src`/`alt`, `text.field`) - это
`{ field: "cover_art_url" | "title", transform?: "firstLetterUpper" }` - `field` представляет
собой закрытый allowlist свойств `Game` (а не "любое свойство, которое есть у этого объекта
игры"), а `transform` - одна из фиксированного набора функций, реализованных на хосте и
диспетчеризуемых по совпадению имени, никогда не произвольное выражение.

### Пример: изображение с заполнителем-заглушкой

```json
{
  "cardVisual": {
    "type": "if",
    "test": { "field": "cover_art_url" },
    "then": {
      "type": "image",
      "class": "cover",
      "src": { "field": "cover_art_url" },
      "alt": { "field": "title" }
    },
    "else": {
      "type": "element",
      "tag": "div",
      "class": "cover-placeholder",
      "children": [{ "type": "text", "field": { "field": "title", "transform": "firstLetterUpper" } }]
    }
  }
}
```

## `fontFaces`: проверка полей

Каждая запись - это `{ family: string, url: string, weight?: string, style?: string }`,
загружаемая как настоящее правило `@font-face`. Поскольку это недоверенное содержимое манифеста,
попадающее напрямую в реальный блок `<style>`, каждое поле проверяется по строгому allowlist
перед формированием любого текста CSS (`theme/fontFaceRegistry.ts`) - запись, не прошедшая любую
из этих проверок, отбрасывается (с записью в лог), а не приводится к безопасному виду, и не
блокирует загрузку остальной части темы:

| Поле | Обязательно | Ограничение |
|---|---|---|
| `family` | да | Только буквы, цифры, пробелы, дефисы, 1-100 символов - специально исключает символы (`"`, `'`, `;`, `{`, `}`), которые понадобились бы для попытки CSS-инъекции. |
| `url` | да | Должен парситься как URL `https:`, дополнительно проверяется на отсутствие `"`, `'`, `;`, `{` или `}`. |
| `weight` | нет | Тот же безопасный по символам паттерн, что и `family`, 1-30 символов. |
| `style` | нет | Должно быть точно `"normal"`, `"italic"` или `"oblique"`. |

```json
{
  "fontFaces": [
    {
      "family": "My Custom Font",
      "url": "https://raw.githubusercontent.com/you/your-theme-repo/<commit-sha>/my-font.woff2",
      "weight": "400"
    }
  ]
}
```

Ссылайтесь на загруженный шрифт по имени в `--font-family` внутри `cssVariables` (см. ниже),
чтобы фактически его применить, - объявление записи `fontFaces` лишь делает шрифт доступным, оно
само по себе нигде его не использует.

## `cssVariables`: доступные токены

Каждый токен ниже - это реальное пользовательское CSS-свойство, для которого `styles.css` либо
устанавливает значение по умолчанию, либо читает его через фолбэк
(`var(--your-token, <default>)`), вообще не объявляя его. Установка чего-либо не из этого списка
всё равно работает (это обычное пользовательское CSS-свойство, ничто этому не мешает), но ничто
в собственной таблице стилей приложения его не прочитает.

### Базовые токены (всегда имеют значение)

Они устанавливаются на `:root` с реальным значением по умолчанию - переопределите любое
подмножество; неустановленные сохраняют значение по умолчанию ниже. Значения по умолчанию взяты
из цветовой схемы [Catppuccin Latte](https://github.com/catppuccin/catppuccin), которая также
является поставляемой по умолчанию темой приложения - если вы создаёте светлую тему, эти цветовые
значения - разумная отправная палитра для сравнения с вашей собственной.

| Токен | По умолчанию | Примечания |
|---|---|---|
| `--color-base` | `#eff1f5` | Фон страницы. |
| `--color-mantle` | `#e6e9ef` | Слегка утопленная поверхность (например, фоны липких заголовков). |
| `--color-crust` | `#dce0e8` | Самый тёмный/насыщенный из тройки base/mantle/crust - `--color-tint` по умолчанию равен ему. |
| `--color-text` | `#4c4f69` | Обычный текст основного содержимого. |
| `--color-text-reverse` | `#ffffff` | Точка противоположной яркости от `--color-text`, для размещения поверх непредсказуемо яркого фонового изображения (например, задника страницы деталей игры), где обычный цвет текста не может гарантировать контраст. |
| `--color-subtext` | `#5c5f77` | Второстепенный текст (подсказки, вторичные метки). |
| `--color-surface0` | `#ccd0da` | Границы, тонкие заливки. |
| `--color-surface1` | `#bcc0cc` | Немного более выраженные границы/заливки, чем `--color-surface0`. |
| `--color-accent` | `#1e66f5` | Основной акцент (кнопки отправки, активные вкладки/навигация, кольца фокуса). |
| `--color-accent-alt` | `#8839ef` | Вторичный акцент. |
| `--color-danger` | `#d20f39` | Разрушительные действия (удаление). |
| `--color-button-text` | `var(--color-text)` | Цвет текста/иконок для нейтральных кнопок - отдельно от `--color-text`, чтобы тема с насыщенными фонами кнопок могла переопределить только это. |
| `--color-on-accent` | `var(--color-base)` | Цвет текста/иконок для всего, что рендерится поверх `--color-accent` (кнопки отправки, активные вкладки, тосты). |
| `--color-tint` | `var(--color-crust)` | Тонирование фона для скрима обложки-арта (строки списка, строки статистики) - должно быть темнее/насыщеннее, чем `--color-base`, для реального контраста после смешивания с прозрачностью. Переопределите, если ваш `--color-crust` плохо сочетается с вашим `--color-text` (см. [Модель безопасности](./security-model) для математики контраста, стоящей за этим). |
| `--space-1` … `--space-6` | `0.25rem` … `2rem` | Шкала отступов (`0.25rem`, `0.5rem`, `0.75rem`, `1rem`, `1.5rem`, `2rem`). |
| `--radius-sm` | `4px` | Маленький радиус скругления углов. |
| `--radius-md` | `6px` | Радиус скругления по умолчанию (большинство элементов управления). |
| `--radius-lg` | `8px` | Больший радиус скругления (строки, панели). |
| `--radius-xl` | `10px` | Наибольший радиус скругления. |
| `--button-border-width` | `1px` | Ширина границы кнопки по умолчанию. |
| `--shadow-sm` / `--shadow-md` / `--shadow-lg` | нарастающее размытие `rgba(0,0,0,...)` | Шкала возвышения (elevation). |
| `--font-family` | `Inter, Avenir, Helvetica, Arial, sans-serif` | Гарнитура всего интерфейса - каждый элемент либо наследует её напрямую, либо устанавливает `font-family: inherit`. Сочетайте с записью `fontFaces`, если нужная гарнитура не является системным шрифтом. |

### Опциональные хуки (не объявлены по умолчанию)

У них нет значения по умолчанию на `:root` - приложение использует их только через
`var(--token, <fallback>)`, так что неустановленный хук незаметно откатывается к показанному
значению, не давая эффекта, пока вы его не установите.

| Токен | Фолбэк, если не установлен | Влияет на |
|---|---|---|
| `--button-border-color` | `var(--color-surface0)` | Цвет границы нейтральной кнопки. |
| `--button-radius` | `var(--radius-md)` | Радиус скругления углов нейтральной кнопки. |
| `--card-border-width` | `1px` | Ширина границы карточки игры / строки списка / строки статистики. |
| `--card-radius` | `var(--radius-lg)` | Радиус скругления карточки игры / строки списка / строки статистики. |
| `--cover-placeholder-background` | `var(--color-surface0)` | Фон заполнителя при отсутствии обложки (принимает любое валидное значение `background`, например паттерн `repeating-linear-gradient(...)`, а не только сплошной цвет). |
| `--tile-background` | `none` | Фон плитки Big Picture. |
| `--tile-border-width` | `3px` | Ширина границы плитки Big Picture. |
| `--tile-border-color` | `transparent` | Цвет границы плитки Big Picture. |
| `--tile-radius` | `var(--radius-xl, 10px)` | Радиус скругления плитки Big Picture. |
| `--tile-focus-shadow` | `var(--shadow-lg)` | Тень/кольцо состояния фокуса плитки Big Picture. |
| `--accent-active-background` | `var(--color-accent)` | Фон активной навигации/вкладки/тега-фильтра - отдельно от `--color-accent`, чтобы цвет акцента темы не заставлял индикатор активного состояния совпадать с ним. |
| `--accent-active-color` | `var(--color-on-accent)` | Цвет текста/иконок для активного состояния навигации/вкладки/тега-фильтра. |

Существует ещё несколько опциональных хуков на уровне отдельных компонентов, а не в
`styles.css` (например, `--balloon-background`/`--balloon-font-family` у `GameCard.vue`,
`--tile-title-font-family` у `BigPictureTile.vue`) - они не каталогизированы здесь исчерпывающе,
но следуют точно тому же паттерну `var(--token, fallback)`, так что поиск (grep) `var(--` в блоке
`<style>` компонента их найдёт.

## Пример: более полный манифест темы

```json
{
  "id": "my-theme",
  "name": "My Theme",
  "version": "1.0.0",
  "kind": "theme",
  "cssVariables": {
    "--color-base": "#1e1e2e",
    "--color-mantle": "#181825",
    "--color-crust": "#11111b",
    "--color-text": "#cdd6f4",
    "--color-text-reverse": "#000000",
    "--color-accent": "#89b4fa"
  }
}
```
